Privacy Policy — YouTube Dashboard

Last updated: 4 October 2026.

YouTube Dashboard is a private, personal analytics tool operated by Evgenii Gusev (contact: evgenii.gusv@gmail.com) for his own YouTube channels. It is not offered to the public.

What data it accesses

With the channel owner's consent (Google OAuth), the app reads, read-only, the owner's YouTube channel data via the YouTube Data API, YouTube Analytics API and YouTube Reporting API: channel and video metadata, view, watch-time, engagement, audience, traffic-source and (if available) revenue statistics. Scopes: youtube.readonly, yt-analytics.readonly, yt-analytics-monetary.readonly.

How it is used

The data is used only to display statistics and charts to the channel owner in this dashboard. The app cannot upload, edit or delete anything on YouTube.

Storage and sharing

Collected statistics are stored encrypted (AES-256-GCM) and shown only to the owner. The OAuth refresh token is stored as an encrypted secret of the owner's GitHub repository. No data is sold, shared with third parties, or used for advertising. No cookies or trackers are used.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. On request to the contact address, all stored data is deleted.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
